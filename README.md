# Portfolio Site
## Tech Stack
ReactJS , EmailJS, Javascript , TailwindCss


## Features
My personal detailed portfolio with Home page , contact section , project page and most importantly about page. I added EmailJS as a way to contact me. Added dark mode and light mode ,added icons from react-icons or simple-icons. Used tailwind for the designing and fonts from google.This site is responsive for both mobile phones and computers.

## Run it locally 
### 1. clone the repo
```
git clone https://github.com/aleezazahra/portfolio/
```

### 2. go to the project folder
```
cd portfolio
```

### 3. Run the server
```
npm run dev
```

### 4. Open in browser
